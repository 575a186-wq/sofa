## Что проверяем (по методу 4.1 + воронка 4.6, шаг 4)

Валидация — **вручную в браузере** (eRank/EverBee без API, скрапинг запрещён ToS).
На каждую нишу 15 минут, 6 критериев:

| Критерий | Что смотрим | Оценка |
|---|---|---|
| 1. Живой спрос | В топе Etsy-выдачи есть листинги свежее 2–3 мес | да / частично / нет |
| 2. Не монополия | Топ не забит 1-2 магазинами-гигантами | да / частично / нет |
| 3. Реальные продажи | EverBee: у топ-5 есть продажи за последние месяцы | да / частично / нет |
| 4. POD-маржа | Продажная цена ≥ $15 (себестоимость постера ~$8–12) | да / частично / нет |
| 5. Узкий угол | Легко сузить «луковицей» (повод/аватар, напр. «марафон → трасса» | да / частично / нет |
| 6. Понятно с фото | Ниша читается по картинке без текста/видео | да / частично / нет |

**Вердикт: 5-6 «да» → ниша в approved. 3-4 → с осторожностью. ≤2 → отказ.**

## Порядок проверки одной ниши (15 мин)

1. **eRank** (eRank.com → Keyword Research, бесплатный тариф хватит)
   — вбить главную фразу → записать объём поиска и конкуренцию.
2. **Etsy руками** — тот же запрос в поиске Etsy → оценить топ-10 по критериям
   «1 свежесть», «2 монополия», «4 цена», «6 фото».
3. **EverBee** (расширение браузера, оценка продаж) → критерий 3.
4. Критерий 5 (узкий угол) — придумать 3 конкретных повода/аватара.
