## 1. Происхождение идеи

Проект вдохновлён видео YouTube-канала **Asian Dad Energy** ("I Got Laid Off... Now I Make $11,000 a Month Doing Whatever I Want", таймкод ~11:55) и статьёй в его Substack-рассылке **"I Let AI Start a Side Hustle for Me… and It Actually Made Money"** (asiandadenergy.substack.com).

### Что сделал автор оригинального эксперимента
Бывший инженер из Big Tech построил автономную систему:
1. Планирование архитектуры в диалоге с ChatGPT-5 (как с соархитектором)
2. Сгенерировал PRD → отдал реализацию кодинг-агенту на базе **Claude Haiku**
3. Пайплайн на **n8n**, оркеструющий Node.js-задачи:
   - поиск ключевых слов
   - анализ успешных товаров-конкурентов
   - генерация арта через генеративные модели
   - подготовка маркетинговых материалов
   - синдикация через **Printify** → **Etsy + Amazon**

### Результаты и уроки (важно не повторить ошибки)
- Опубликовано ~200 товаров, за месяц: **$600 (Etsy) + $70 (Amazon)**, чистыми ~**$200**
- **~1 из 15 изображений** — с визуальным браком, не ловится автоматикой
- Некоторые генерации опасно близко подходили к чужим стилям/IP
- Синхронизация с маркетплейсами была хаотичной: листинги падали, варианты разъезжались, метаданные требовали ручной правки
- Главный вывод автора: при полной автоматизации без сужения ниши система не создаёт ценность, а просто "заливает" рынок производными работами — **это не инновация, а ускорение без направления**
- Спустя месяцы простоя листинги всё ещё приносят небольшой стабильный доход еженедельно

**Ключевой вывод для нашей реализации:** держать человека на 1-2 критических точках контроля (проверка кандидатов ниш, выборочная проверка изображений перед масштабированием), не пытаться убрать 100% ручного участия.

## 4. Этап "Исследование ниши" — ядро методологии

### 4.1 Пять критериев хорошей ниши

| # | Критерий | Суть |
|---|---|---|
| 1 | Есть спрос | Реальные покупки, не просто хайп |
| 2 | Конкуренция не забита | Топ-выдача — не десятки магазинов-миллионников |
| 3 | Подходит под POD | Хорошо переносится на постер/канвас/футболку |
| 4 | Достаточно узкая | Категория → под-ниша → микро-ниша → аватар/повод |
| 5 | **Automation-fit (новая ось)** | Можно ли надёжно автоматизировать без потери качества/риска IP |

### 4.2 Метод "луковицы" (сужение ниши)

```
Категория   → Wall Art
Под-ниша    → Pet Portraits
Микро-ниша  → Dachshund Art
Аватар/повод → "Dachshund mom gift" / "Vintage motorcycle dachshund poster"
```

### 4.3 КЛЮЧЕВАЯ РАЗВИЛКА: два типа AI-арта

**Тип A — генеративный** (то, что делал автор оригинала)
Промпт → диффузионная модель → картинка. Непредсказуемо, риск брака (1/15), риск IP-схожести со стилем. Требует человеческого QA каждой единицы.

**Тип B — параметрический/процедурный** (рекомендуемый подход для нас)
Данные → шаблон/код (SVG/render) → детерминированный результат. Не "рисует", а рендерит по формуле. Почти нет брака, почти нет IP-риска (дизайн твой, не "стиль" чужой модели).

**Для цели "максимальная автоматизация через AI-агентов" — Тип B на порядок надёжнее.**

### 4.4 Кандидаты ниш типа B (параметрические, для проверки в первую очередь)

| Ниша | Источник данных | Автоматизация | Насыщенность |
|---|---|---|---|
| Карта по координатам/адресу | Lat/long/адрес → map API | Полная | Огромная (нужен острый угол, напр. "серф-спот", "маршрут забега") |
| Звёздная карта неба на дату/место | Дата+локация → астрономический API | Полная | Средняя, проверенная |
| Звуковая волна (waveform) | Аудиофайл → рендер | Полная | Средняя, растёт |
| Натальная карта/зодиак | Дата+время+место рождения → эфемериды | Полная | Средняя-высокая |
| Генеалогическое древо | Имена+даты (форма) → рендер | Полная (нужен ввод юзера) | Ниже, стабильный спрос |
| Путь пробежки/похода (GPX) | GPX-файл → line-art | Полная | Растущая, менее забита |
| Значение имени + статистика рождения | Имя+дата → текст+визуал шаблон | Полная | Стабильная |

### 4.5 Инструменты исследования (с чем работать)

| Инструмент | Роль | Есть публичный API? |
|---|---|---|
| **eRank** | Keyword research + listing audit | ❌ Нет — только ручная проверка |
| **EverBee** | Product research, оценка продаж конкурентов | ❌ Нет — только ручная проверка |
| **Marmalead** | Глубокая аналитика ключей + тренды | ❌ Нет |
| **EtsyHunt / Sale Samurai** | База конкурентов, дешёвая альтернатива | ❌ Нет |
| **Etsy Open API v3** | `findAllListingsActive` — кол-во листингов, цены, даты | ✅ Да, простой API-key (developer.etsy.com), OAuth не нужен для read |
| **Google Trends** | Подтверждение реального интереса, динамика | ⚠️ Неофициально — `pytrends` (реверс-инжиниринг), либо MCP-обёртки (напр. trendsmcp.ai) |
| **Pinterest Trends** | Ранний сигнал (опережает Google/Amazon на 2-4 недели) | ❌ Нет публичного API, нет экспорта — только ручной просмотр |

**Важный вывод:** eRank/EverBee/Marmalead/Pinterest Trends — НЕ автоматизировать скрапингом (нарушение ToS, риск бана). Это осознанная точка ручного контроля.

### 4.6 Порядок воронки (не заменять один источник другим!)

```
1. Pinterest Trends + TikTok (#etsyfinds) → сырые идеи (разведка, опережают рынок)
2. Google Trends → отсеять угасающее/фаддовое (нужен горизонт 6-24 мес, не 2-8 недель)
3. Etsy Open API (findAllListingsActive) → реальный объём + конкуренция на площадке
4. eRank/EverBee (ВРУЧНУЮ, только для финального шортлиста 3-5 кандидатов) → окончательная проверка
```

Каждый источник закрывает то, что не видит другой:
- Google/Pinterest = верх воронки (осведомлённость), не показывают конкуренцию и реальную покупательскую готовность
- Etsy = низ воронки (покупка), но слепа к трендам, которые ещё не пришли на площадку

### 4.7 Формула скоринга (черновик)

```
opportunity_score =
    (trend_slope_weight * google_trends_growth_pct) +
    (social_weight * tiktok_mentions_growth_pct) -
    (competition_weight * log(etsy_listing_count)) +
    (freshness_weight * (1 / avg_age_days_of_top_listings))

automation_fit_score =
    1.0  если ниша параметрическая (Тип B — карты, звёздные карты и т.п.)
    0.3–0.5  если чисто генеративная (Тип A, нужен человеческий QA)

final_score = opportunity_score * automation_fit_score
```

### 5.3 Черновик PRD.md (для передачи агенту)

```markdown
# Niche Research Pipeline — PRD

## Цель
Скрипт, который раз в неделю:
1. Берёт список seed-тем из config/candidate_seeds.yaml
2. Для каждой темы запрашивает Google Trends (pytrends) — interest over time за 12 мес.
3. Для каждой темы запрашивает Etsy Open API v3 (findAllListingsActive) —
   количество активных листингов, средние цены, даты создания топ-20
4. Считает opportunity_score по формуле (см. п.4.7 project memory)
5. Сохраняет топ-15 в output/weekly_report.md с обоснованием

## Технические требования
- Python 3.11+, зависимости через requirements.txt
- Etsy API key — переменная окружения ETSY_API_KEY
- Retry с экспоненциальной паузой при rate limits/ошибках API
- НЕ трогать eRank/EverBee — проверяются вручную
- Логи в output/logs/ с датой запуска

## Что НЕ делать
```
